# AgentChess MVP 0.5.10 — технічний опис

**Основа:** фронтенд оновлення MVP 0.5.9, не попередній 0.5.7.

## Реалізовано

1. Drag & Drop мишею/тачпадом через `pointerdown`, `pointermove`, `pointerup`, `pointercancel`, із порогом 6 px для розрізнення кліку й перетягування.
2. Анімовані переміщення фігур у CSS-плаваючому шарі (подвійний `requestAnimationFrame` + `transform`). Для рокірування — два рухомі елементи.
3. Повернення перетягнутої фігури при нелегальному або неавторському ході. Сервер залишається джерелом істини.
4. Швидкість 0 / 200 / 400 / 700 / 1000 мс у бічних налаштуваннях; збереження у `localStorage`.
5. Підсвічування початкового та кінцевого полів останнього ходу.
6. Підтримка миші й тачпада без нативного HTML Drag & Drop; два кліки також збережені.
7. Увімкнення підсвітки атакованих полів вибраної фігури, що належить стороні ходу; пішаки, кінь, король і ковзні фігури; зупинка на першому зайнятому полі.
8. Ходи CDB, відповіді Stockfish, переходи вперед/назад історії партії та перегляду дерева авторських варіантів відображаються анімовано, коли є відповідний UCI.

## Що не змінюється

Бекенд FastAPI, SQL-каталог, SQLite, імпорт CDB, перевірка ходів через `python-chess`, авторські рішення, правила класифікації матових задач. Зокрема, **задача №3041 із `polgar.ru.cdb` не змінюється**.

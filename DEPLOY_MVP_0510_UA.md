# AgentChess MVP 0.5.10 — установлення

## Передумови
- Установлено **MVP 0.5.9** (або ту саму версію `frontend/index.html` із фільтрами каталогу «Тема → CDB → № задачі»).
- Робоче середовище Xubuntu, Conda `agentchess`, FastAPI запускається через `./run.sh`.
- Архів містить **лише HTML/JavaScript/CSS, тест та документацію**. Він не змінює `backend`, `data/agentchess.sqlite3`, CDB, авторські варіанти чи статистику.

## Установлення

1. Зупинити FastAPI: **Ctrl+C** в терміналі сервера.
2. Перейти в каталог вашої **діючої** інсталяції (приклад):
   ```bash
   conda activate agentchess
   cd ~/kafedra/Chess/chess_agent/AgentChess_MVP_05_5
   ```
3. Зробити резервну копію поточного фронтенду:
   ```bash
   mkdir -p backups
   cp frontend/index.html backups/index_before_0510.html
   ```
4. Розпакувати ZIP (якщо браузер зберіг його у `~/Downloads`):
   ```bash
   unzip -t ~/Downloads/AgentChess_MVP_0510_UPDATE.zip
   mkdir -p /tmp/agentchess0510
   unzip -oq ~/Downloads/AgentChess_MVP_0510_UPDATE.zip -d /tmp/agentchess0510
   ```
5. **Скопіювати лише фронтенд і тест**, не всю папку:
   ```bash
   cp /tmp/agentchess0510/AgentChess_MVP_02/frontend/index.html frontend/index.html
   cp /tmp/agentchess0510/AgentChess_MVP_02/tests/test_board510.cjs tests/test_board510.cjs
   ```
6. Перевірити JavaScript (потрібен Node.js, тільки для тестів):
   ```bash
   node --test tests/test_board510.cjs
   ```
   Очікується **8 passed, 0 failed**.
7. Запустити сервер:
   ```bash
   export STOCKFISH_PATH=/usr/games/stockfish
   ./run.sh
   ```
8. Відкрити http://127.0.0.1:8000 і натиснути **Ctrl+Shift+R** у Firefox. Заголовок має показувати **AgentChess · MVP 0.5.10**.

## Параметри тренажера

У бічному меню «☰ Меню» → «Вигляд тренажера»:
- **Швидкість анімації**: 0 / 200 / 400 / 700 / 1000 мс (за замовчуванням 400 мс).
- **Підсвітка атакованих полів**: увімкнено / вимкнено (за замовчуванням вимкнено).
- Параметри зберігаються у `localStorage` браузера.

## Ручна перевірка

1. Розпочати вправу, **натиснути** власну фігуру, натиснути поле призначення. Фігура повинна рухатися плавно, якщо анімацію ввімкнено.
2. Розпочати нову вправу, **затиснути** фігуру лівою кнопкою і перенести на поле. Фігура має слідувати за курсором.
3. Вибрати **неправильний авторський** або нелегальний хід перетягуванням. Фігура має повернутися на вихідне поле; червона рамка відображає помилку. У CDB-вправах сервер продовжує порівнювати з авторським рішенням.
4. Зробити правильний хід у вправі, яка має відповідь суперника. Автоматична відповідь має бути анімована.
5. Зіграти зі Stockfish: після вашого ходу має бути анімовано відповідь рушія.
6. Увімкнути підсвітку атакованих полів; вибрати фігуру сторони, яка зараз ходить. Атаковані поля матимуть сині маркери (на зайнятих полях — синя рамка).
7. Перевірити відображення жовтих позначок початкової та кінцевої клітинок останнього ходу.
8. Перевірити шахівницю в перевернутому стані, промоцію та рокірування (за наявності відповідних позицій).
9. Відкрити «Рішення» і перегорнути записані ходи кнопками ◀ / ▶. Так само перевірити історію партії.
10. Перевірити, що каталог MVP 0.5.9 продовжує фільтрувати за темою, CDB та номером.

## Семантика підсвітки

Показуються саме **поля, які атакує фігура за її геометрією** (наприклад, пішаки атакують діагонально вперед незалежно від наявності цілі). Для лінійних фігур промінь обривається на першій зайнятій клітинці, але клітинка включається. Це **не список юридично допустимих ходів**: зв'язки, шах власному королю та спеціальні умови рокірування не враховуються. Легальність ходу, як і раніше, визначає `python-chess` на сервері.

## Відомі обмеження та безпека

- На клієнті проміжні кадри авторської відповіді обчислюються локально із серверних UCI; **кінцевий FEN завжди береться із серверної відповіді**.
- Фронтенд не змінює шахових правил і не переоцінює авторські рішення.
- Налаштування швидкості впливає на переміщення фігури, а не на час розрахунку Stockfish.
- Тести JavaScript перевіряють обчислення атак, проміжних позицій і наявність UI. Повноцінне автоматизоване тестування інтерфейсу у Firefox/Chromium у середовищі збірки **не виконувалося** — необхідна ручна перевірка за пунктами вище.

# AgentChess MVP 0.5.11 — пакет оновлень

База: архів `AgentChess_MVP_05_10.tar(1).gz` (MVP 0.5.10).

## Що змінено

1. **Постійна навігація під дошкою.** Кнопки ◀ ▶ розміщені під шахівницею і не зникають. Вони керують авторським деревом (коли воно відкрите), історією вирішеної задачі, історією партії або результатом Stockfish. На краях історії кнопки неактивні. Для поточної партії перший клік ◀ завантажує історію сервера, далі перегляд покроковий.
2. **Стандартні налаштування.** Якщо параметри ще не записані в localStorage, фігури показуються контрастними символами; підсвітка атакованих полів увімкнена. Явні зміни користувача зберігаються.
3. **Мат.** Підсвітка короля при підтвердженому маті світло-червона. API `GET /api/position/status?fen=...` незалежно визначає мат за правилами python-chess. При розв’язуванні матової задачі легальний мат приймається навіть поза CDB-лінією. Якщо авторську лінію завершено без мату, це відображається окремо.
4. **Завершення Stockfish.** Результат «Дограти зі Stockfish» та «Stockfish розв'язує» відкривається на останній позиції. Після закриття перегляду результату аналізу залишається кінцева позиція, повторне відкриття історії — стрілками під дошкою.

## Змінені файли

- `frontend/index.html` — інтерфейс, стан історії, підсвітка мату.
- `backend/app.py` — новий маршрут перевірки мату.
- `backend/exercise04.py` — підтвердження справжнього мату і уточнення результату задачі.
- `tests/test_board511.cjs` — статичні регресійні тести MVP 0.5.11.

## Установлення на сервері

Зробіть резервну копію застосунку і бази, особливо `data/agentchess.sqlite3`. Розпакуйте пакет у кореневій директорії застосунку, зберігши структуру `frontend/`, `backend/`, `tests/`. **Базу даних пакет не містить і не змінює.** Відновіть сервіс systemd відповідно до назви свого сервісу (наприклад, `sudo systemctl restart agentchess`). Для GitHub: скопіюйте ці файли в клон, перевірте `git diff`, закомітьте та виконайте `git push`; на сервері оновіть код через `git pull --ff-only` і перезапустіть сервіс.

## Перевірки

- `node --test tests/test_board510.cjs tests/test_board511.cjs`
- `python -m compileall -q backend`
- Ручна перевірка із запущеним FastAPI + python-chess + Stockfish: мат у різних позиціях, завершена задача, початкова і фінальна позиції Stockfish, відновлення дошки після закриття історії, мобільна ширина.

Тести JavaScript (12 із 12) та компіляція Python пройшли у середовищі складання. Інтеграційні Python-тести та реальна взаємодія зі Stockfish тут не виконувалися, оскільки в середовищі немає встановленого python-chess/Stockfish. Новий API потрібно розгортати разом із фронтендом.

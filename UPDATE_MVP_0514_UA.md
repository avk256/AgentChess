# AgentChess MVP 0.5.14 — редактор позиції безпосередньо на шахівниці

**База для оновлення:** AgentChess MVP 0.5.13. **База даних не змінюється.**

## Можливості

- У темі **Гра зі Stockfish** натисніть **Редактор позиції на дошці** у налаштуваннях (або **Редагувати позицію** над завданням під час гри).
- Виберіть фігуру з палітри й клацніть поле дошки, щоб її додати/замінити.
- **Перемістити**: клацніть початкове поле, потім кінцеве. Альтернатива — перетягування на дошці.
- **Стерти**: клацніть фігуру, яку слід прибрати. **Очистити дошку** та **Початкова позиція** доступні окремо.
- Задайте, кому ходити (`Білі` / `Чорні`). Для спеціальних позицій встановіть права рокіровки `K Q k q` і, за потреби, поле en passant. Після будь-якої зміни фігур ці права скидаються до `-`, їх потрібно за потреби встановити повторно.
- Поле FEN формується автоматично; ручне введення FEN залишається можливим.
- Натисніть **Застосувати й почати партію**. Сервер перевіряє позицію через `python-chess`; невалідна або вже завершена позиція не створює партію.
- **Скасувати** повертає дошку до попереднього стану. Наявна партія не переписується під час редагування: підтвердження створює **нову** партію. Для позиції, де хід протилежної сторони, Stockfish може зробити перший хід автоматично.

## Локальне встановлення (Xubuntu)

Зупиніть попередній локальний процес `./run.sh` клавішами `Ctrl+C`. Завантажте `AgentChess_MVP_05_14_update.tar.gz` у `~/Downloads`.

```bash
conda activate agentchess
cd ~/kafedra/Chess/chess_agent/AgentChess_MVP_05_5
mkdir -p backups /tmp/agentchess0514
cp frontend/index.html backups/index_before_0514.html
cp backend/app.py backups/app_before_0514.py
tar -tzf ~/Downloads/AgentChess_MVP_05_14_update.tar.gz
tar -xzf ~/Downloads/AgentChess_MVP_05_14_update.tar.gz -C /tmp/agentchess0514
cp /tmp/agentchess0514/frontend/index.html frontend/
cp /tmp/agentchess0514/backend/app.py backend/
cp /tmp/agentchess0514/tests/test_board514.py tests/
cp /tmp/agentchess0514/UPDATE_MVP_0514_UA.md ./
python -m compileall -q backend
python -m pytest tests/test_board514.py tests/test_board513.py tests/test_board512.py -q
python -m pytest tests/ -q
export STOCKFISH_PATH=/usr/games/stockfish
./run.sh
```

У Firefox відкрийте локальну адресу застосунку та натисніть `Ctrl+Shift+R`. **Не запускайте локально uvicorn вручну**: використовуйте тільки `./run.sh`.

## Ручна перевірка

1. Виберіть тему **Гра зі Stockfish**, відкрийте редактор.
2. Видаліть фігуру та поставте її на інше поле; переконайтеся, що FEN змінюється.
3. Перемістіть фігуру кліками та перетягуванням.
4. Натисніть **Скасувати** — повернулася стара позиція.
5. Повторно відкрийте редактор; очистіть дошку: початок гри повинен бути відхилений сервером.
6. Встановіть коректну позицію (наприклад, початкову), вкажіть сторону ходу та натисніть **Застосувати й почати партію**.
7. Зробіть декілька ходів; перевірте історію стрілками під дошкою, після цього поверніться до останньої позиції.
8. У середині гри знову відкрийте редактор, змініть чернетку та натисніть **Скасувати**: активна партія повинна залишитися без змін.
9. Перевірте обидві теми інтерфейсу (світлу й темну) та орієнтацію для гри чорними.

## Відновлення

При закритому застосунку:

```bash
cp backups/index_before_0514.html frontend/index.html
cp backups/app_before_0514.py backend/app.py
./run.sh
```

Оновлення не додає міграцій SQL і не змінює базу `data/agentchess.sqlite3`.

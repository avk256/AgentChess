# ♞ AgentChess

**AgentChess** — вебзастосунок для інтерактивного навчання шахів на основі оцифрованих баз задач **CDB**, авторських шахових варіантів та рушія **Stockfish**.

**Актуальна версія:** MVP **0.5.10**  
**Мова інтерфейсу:** українська  
**Стек:** Python · FastAPI · SQLite · `python-chess` · Stockfish · HTML/CSS/JavaScript  
**Платформи:** Linux (Xubuntu/Ubuntu); доступ з інших пристроїв через браузер за IP-адресою.

> **Про склад репозиторію.** Оновлення `AgentChess_MVP_0510_UPDATE.zip` — **не самостійний повний дистрибутив**, а фронтенд-патч до встановленої **0.5.9**. Для встановлення з чистого `git clone` репозиторій повинен містити зібрану кодову базу, а підготовлену робочу SQLite потрібно передати окремо або згенерувати через імпорт CDB.

## Призначення

AgentChess об'єднує цифрові шахові книги (CDB), автоматичну підготовку вправ та інтерактивний тренажер. Користувач вибирає тему, джерело та конкретну задачу, розв'язує її на шахівниці, переглядає оригінальне рішення або продовжує гру зі Stockfish. Система зберігає результати спроб.

Авторська лінія з CDB — **навчальний еталон проходження задачі**. Вона не зобов'язана збігатися з найкращою лінією Stockfish і не замінюється автоматично рушієм.

## Можливості

### Підготовка й каталог CDB

- Імпорт вихідних CDB із збереженням оригінального тексту, метаданих, дерева варіантів та коментарів.
- Перетворення й перевірка шахових записів із використанням FEN, PGN, JSON та `python-chess`.
- Класифікація вправ за темами, складністю та джерелами.
- Каталог із **залежними фільтрами «Тема → CDB → оригінальний № задачі»**; пагінація і прямий перехід до номера.
- Перегляд авторського дерева варіантів, включно з позначенням CDB `--` / `0000` там, де воно зустрічається у джерелі.

### Шаховий тренажер

- Розв'язування матових, тактичних, ендшпільних та інших вправ.
- Рух фігур **двома кліками або Drag & Drop** (миша, тачпад).
- **Анімація переміщення фігур** і повернення після помилкового перетягування.
- Підсвічування останнього ходу та, за бажанням, **полів, атакованих вибраною фігурою** сторони ходу.
- Налаштування тривалості анімації: **0 / 200 / 400 / 700 / 1000 мс** (типово 400 мс); збереження налаштувань у `localStorage`.
- Перегляд авторської послідовності вперед/назад; повтор поточної задачі.
- Колірна індикація: зелений — правильний хід, червоний — неправильний, фіолетовий — завершення без помилок (для підтримуваних сценаріїв).
- Гра проти Stockfish та демонстрація гри рушія за обидві сторони з історією ходів.
- Облікові записи, статистика розв'язань і кількість спроб.

> **Атаковані поля ≠ легальні ходи.** Наприклад, пішак атакує діагональні поля, навіть коли на них немає фігури. Серверна перевірка легальності залишається за `python-chess`.

## Встановлення

Наведені команди призначені для **Ubuntu / Xubuntu**. Потрібен **повний репозиторій** зі зібраними виправленнями до 0.5.10, а не ZIP лише з останнім оновленням.

### 1. Системні пакети

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip stockfish sqlite3
```

### 2. Клонування

```bash
git clone git@github.com:YOUR_USERNAME/AgentChess.git
cd AgentChess
```

Замініть `YOUR_USERNAME`. Для приватного репозиторію потрібен налаштований SSH-ключ або інший дозволений спосіб авторизації.

### 3. Залежності Python

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Альтернатива для локальної розробки — наявне Conda-середовище `agentchess`.

### 4. Дані

Для збереження вже імпортованих книг перенесіть власну **узгоджену резервну копію** `data/agentchess.sqlite3` через SSH/SCP. Наприклад, на сервері після копіювання:

```bash
mkdir -p data
sqlite3 data/agentchess.sqlite3 'PRAGMA integrity_check;'
sqlite3 data/agentchess.sqlite3 'SELECT COUNT(*) FROM cdb_exercises;'
```

Для відомої бази очікується `ok` і `14343`. Якщо БД ще немає, використовуйте імпортер базової версії проєкту, а не просто створюйте порожній файл. Не запускайте повторний `--rebuild` поверх робочої бази з користувачами й результатами без резервної копії.

### 5. Локальний запуск

```bash
export STOCKFISH_PATH=/usr/games/stockfish
./run.sh
```

Відкрийте **http://127.0.0.1:8000**. Після оновлення фронтенду зробіть у браузері **Ctrl+Shift+R**.

## Запуск і доступ зі смартфона

Для доступу в **довіреній локальній мережі** запустіть FastAPI з прив'язкою до мережевого інтерфейсу:

```bash
source .venv/bin/activate
export STOCKFISH_PATH=/usr/games/stockfish
python -m uvicorn app:app --app-dir backend --host 0.0.0.0 --port 8000
```

На сервері перегляньте IP:

```bash
hostname -I
```

На смартфоні, підключеному до тієї самої мережі, відкрийте `http://SERVER_IP:8000`. Якщо активовано UFW, дозвольте порт **лише своїй LAN-підмережі**. Для доступу через мобільний інтернет використовуйте VPN (наприклад, Tailscale) або HTTPS із належним захистом.

> Поточний інтерфейс підтримує Pointer Events; зручність на малих сенсорних екранах потрібно перевіряти окремо. Не слід вважати цю версію повністю адаптованим мобільним застосунком/PWA.

## Тестування

```bash
python -m compileall -q backend
python -m pytest tests/ -q
```

Для перевірки анімації та логіки шахівниці в 0.5.10 потрібен Node.js:

```bash
node --test tests/test_board510.cjs
```

У звіті до пакета 0.5.10 зафіксовано **8 успішних JavaScript-тестів**. Повне браузерне тестування з реальним FastAPI та Stockfish на всіх цільових пристроях не підтверджено. Перед публічним розгортанням перевірте також авторизацію, індивідуальні дані користувачів і мережевий доступ.

### Деталі ключових етапів

#### 0.2–0.2.1 — оцифрування джерел

Створено основу каталогізації CDB і перевірки шахових записів. В архіві з 34 фізичних файлів виявлено 33 унікальні джерела. Патч 0.2.1 виправив синтаксис перетворень пішаків, які не завжди коректно інтерпретувалися шаховим парсером.

#### 0.3–0.4.2 — перехід до навчального тренажера

Реалізовано сесії, перевірку правильності, журнал спроб і взаємодію з шахівницею. Відкрито всі 7 851 кандидат у вправи; система навчилася проходити повні авторські послідовності, показувати підказки та відтворювати рішення по ходах.

#### 0.5–0.5.6 — розширення навчального матеріалу

Після включення раніше невикористаних джерел каталог виріс до 14 343 вправ. Додано теми, дерево CDB-варіантів, кольорову індикацію і складніші режими Stockfish. Подальші патчі уточнили класифікацію та виправили регресії тестів.

#### 0.5.7–0.5.9 — виправлення та розвиток каталогу

Уніфіковано запити за темами вправ, усунено помилку, коли вибране значення містило суфікс на кшталт `тактичні комбінації (3393)`, додано вибір джерела й оригінального номера задачі.

#### 0.5.10 — інтерактивність шахівниці

Додано перетягування фігур, анімацію автоматичних і ручних ходів та візуальне навчальне підсвічування. **Шахова логіка, SQLite, авторські варіанти та класифікація матових задач у цьому фронтенд-оновленні не змінювалися.** Зокрема, `polgar.ru.cdb`, задача №3041, залишилася в попередньому вигляді.

## Обмеження та безпека

- Наявність 14 343 вправ залежить від підготовленої бази; ці дані не виникають автоматично після клонування коду.
- Авторська лінія CDB може містити тільки ключовий хід або неповне продовження; вона є критерієм авторської вправи, а не доказом єдиного можливого шахового розв'язку.
- CDB `--` / `0000` не є звичайним ходом фігури; під час перегляду дерева такі позначки обробляються окремо.
- Налаштування швидкості анімації змінює тривалість **відображення ходу**, а не час обчислення Stockfish.
- Не публікуйте робочу SQLite, токени, паролі, `.env`, копії користувацьких даних у GitHub. Використовуйте `.gitignore` і перевіряйте `git status` перед комітом.
- Для доступу за публічною IP-адресою налаштуйте HTTPS/VPN та обмеження доступу; відкритий HTTP не підходить для передавання паролів і токенів через інтернет.
- Повні end-to-end перевірки роботи на телефонах, анімацій і Stockfish потрібно проводити на цільовому розгортанні.
